# V0.2 M1：独立猫爪币钱包

完成日期：2026-10-21。本阶段结束于M1，没有签到、连续奖励、商城、家具购买或额外入住。

## 现状检查与改动

改动前：IndexedDB v4 包含active、records、settings、categories；备份为v4。domain.progress直接返回 coins=experience，完成总结的XP与币也共用earned；没有余额或流水。

现在：IndexedDB升级为v5，新增三个独立存储：

| 存储 | 主键 | 内容 |
| --- | --- | --- |
| wallet | only | balance、totalIncome、totalSpent、remainderMs、migratedAt、活动会话基线、钱包模型version=1 |
| walletTransactions | id | 收入/支出流水；kind、sourceId、amount、description、createdAt |
| coinReceipts | recordId | 每次本地结算的eligibleMs和coins，包括未满5分钟的零币凭据 |

原有存储、历史记录和领养ID保留。domain.progress仅计算XP、等级、当前/下级门槛，XP整分钟算法完全不变；统计页读取wallet.balance，完成总结分别读取earned与coinsEarned。

## 计费和迁移边界

- 全部已保存有效时长每满60秒获得1 XP，等级门槛不变。
- 只有迁移后本机新结算、且此前没有相同记录的有效时长参与新币。每300,000ms获得1币，余数跨会话精确保留；3分钟再2分钟得1币；12分钟得2币余2分钟。
- 放弃不保存、不增加币进度。运行中时长暂不入钱包，到保存时结算。提前保存同样按实际有效时长参与。
- 第一次升级时，钱包余额/收入/支出/余量均为0；旧币此前仅由XP推算，无需删除历史数据。历史记录不创建收入流水。钱包只在oldVersion<5时初始化，重启不会清零。
- 迁移事务记录活动会话在迁移时刻已累计的有效毫秒，不改会话本身。以后保存时从有效总时长扣除此基线；暂停期间不累计；倒计时基线最多为目标时长。迁移前已经到点的会话，即使以后才恢复结算，也不发新币。
- 迁移前未确认的总结保留XP显示，但猫爪币改为0；不把旧提示当新钱包收入。

## 原子性与流水

一笔专注结算在同一readwrite事务中处理active、records、settings、wallet、walletTransactions、coinReceipts：检查记录ID、保存记录、累计余量、更新余额、写发币凭据和正数收入流水、写总结、删除会话。任一写入失败全部回滚。多个页面同结算只会创建一次记录和收入；已有同ID记录不补发。

流水收入为正数，支出为负数。钱包读取及备份校验：余额=收入总额−支出总额=流水金额之和，余量=全部可奖励凭据时长mod300,000；币收入须与凭据对应。0币会话只有凭据，不伪造0金额流水。

内部spendCoins(db,operationId,amount,description,now?)接口验证正整数金额与余额，使用唯一spend:operationId去重；相同操作重复调用不扣第二次，同ID不同内容拒绝，余额不足拒绝。收入/支出与余额写入同一事务；消费不改变XP、等级和专注记录。M1没有消费UI。后续调用界面需像既有存储操作一样刷新状态并发送跨页通知。

预留WalletIncomeKind中的daily_checkin及DAILY_CHECKIN_COINS=5；没有签到入口、日期计算或发放API。

## 备份v5

包含records、categories、可选catHouse、必需wallet快照（状态、流水、凭据）；继续兼容v1–4。旧版导入只合并记录，照常增加XP统计，不补币、不清空现有余额或余量。活动会话、总结查看状态、通知及其他本机设置不导出。

钱包恢复使用保守规则：

1. 余额、流水、余量、凭据及关联记录完整校验后才开始写入。
2. 未有任何新钱包业务的空钱包可恢复快照；有活动专注时，拒绝恢复不同快照，以保护迁移基线。
3. 相同快照重复导入不发币。已有钱包不同于快照时整批拒绝，不相加、不覆盖。
4. 钱包、猫咪、类别、记录在同一导入事务内写入，后续冲突会回滚前面已暂存的钱包。

不同设备已有钱包时，本阶段不提供合并经济流水的能力；不应通过清空浏览器数据来绕过冲突。保留备份文件并按需要在全新且未开始专注的浏览器恢复。

### 自动化与构建

111项测试、20个测试文件通过；生产构建通过。12个新钱包测试覆盖：

- v4迁移保留历史XP/等级/记录/领养，旧币归零、历史不补币、重开不清零。
- 3＋2分钟、12分钟余2分钟、毫秒零头累计。
- 重复/并发结算、重复恢复同一会话，不重复收入。
- 迁移时运行中的正计时、暂停会话、迁移前已到点/跨迁移点倒计时，以及放弃不奖励。
- 幂等支出、同ID冲突、余额不足与并发扣款，消费不影响经验。
- 流水写入失败时，记录/余额/凭据/总结/活动会话整体回滚。
- v5钱包备份、重复恢复、旧v1–4记录不换币、无效钱包拒绝、恢复后再次消费的余额一致。
- 后续类别冲突回滚已暂存钱包，活动会话阻止钱包覆盖。

原有计时、暂停恢复、统计、类别、领养及动画测试一并运行。
