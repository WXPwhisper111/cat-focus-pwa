## 用户行为

任务字段为 id/title/status/createdAt/updatedAt/completedAt。标题去首尾空格，1–100 个 Unicode 字符；允许同名、不同 ID。标题通过文本节点渲染。任务跨午夜保留，支持完成后恢复，删除需要再次确认。

未选目标时，猫咪下方的提示窗高度为 0，计时区保留“下一步，做什么？”入口。选中后显示“待开始”；运行和暂停分别显示对应状态。普通结束、提前保存或放弃后清理当前相同的草稿选择，并收起提示窗，不自动完成任务。未完成任务仍在清单中，可再次选择。

开始后锁定任务 ID 和当时的标题。修改/完成/删除清单任务不会改写正在执行或暂停的目标快照；运行中不开放目标更换/清除。原任务删除时，当前快照和已保存记录继续保留，结束后不产生悬空的可选择目标。总结里的“标记目标已完成”只修改任务，不增加经验或货币。

清单完整内容在抽屉内部滚动，不把所有任务展开到专注页面。抽屉关闭时用 preventScroll 返回入口焦点，不强制滚动整个页面。visualViewport 尺寸变化会更新抽屉可用高度和底部偏移；真实手机键盘行为仍须实机验证。

## 数据兼容与升级

- IndexedDB：v5 → v6，只增加 `focusTasks`，不重写原有时长、钱包、领养和商城数据；有活动会话时也保留原样。
- JSON：v6 → v7，包含任务定义及记录中的目标快照，继续支持 v1–v6。旧 v6 版本元数据仍按 database=5 校验，新 v7 按 database=6 校验。
- 旧会话/记录没有快照时作为自由专注正常处理。
- 任务按 ID 合并；相同 ID 的内容不一致则整批回滚。旧备份不清除本机任务；不会相加两个钱包，也不会从历史任务或专注补发货币。
- 当前任务选择仍属于本机设置，不导出；活动会话仍不进入 JSON 备份。历史任务删除后允许记录保留其独立快照。
- 升级前建议手动备份，关闭其他旧版页面后再联网刷新；旧版本程序无法打开更高版本数据库，v7 备份也应由新版本程序导入。
