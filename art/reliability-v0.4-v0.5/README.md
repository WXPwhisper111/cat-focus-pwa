# V0.4 / V0.5 本地实施报告

## 实现
- notifications.ts：Service Worker 系统通知优先，桌面降级；明确返回权限/能力/失败状态，5 秒调用超时。正常完成按会话 ID 使用通知标签，仍由 created 结算门控去重。测试通知单独标签，不自动请求权限。
- scripts/sw-runtime.js：通知点击聚焦同源窗口并切换专注页，或打开应用；未改变缓存策略。
- main.ts：设置页测试通知、无业务数据诊断；连接数据管理与确认恢复；卸载后的异步渲染保护。
- data-manager.ts：记录/任务/分类数量、JSON 下载发起时间、统计 CSV（不含任务标题，转义公式与引号）、七天设置页备份提醒及持久化开关、导入预览与确认。
- storage.ts：预览调用现有完整导入事务并主动回滚；提交重新校验。界面恢复要求无活动会话；原导入 API 默认兼容原有调用，保留既有冲突和合并语义。
- style.css：暖色、可滚动的备份预览框。
- tests/reliability-data.test.ts、tests/update-worker.test.ts：通知、点击处理、预览回滚、确认界面、并发内容冲突、活动会话保护、CSV 与提醒测试。

数据库仍 v6，备份仍 v8，无账号、云同步、Android 安装包或服务器推送。备份偏好使用 settings，不进入 JSON。提醒计时从首次在数据管理页发现记录/任务或设置偏好开始；不在后台轮询。

## 未验证与限制
- Android Chrome、已安装 PWA、iPhone 主屏幕应用真实系统通知送达、锁屏、声音、系统回收均未实测。
- 未进行真实手机前后台、输入法、短屏横屏或本轮完整 A/B 升级演练；不宣称手机验收全部通过。
- 不保证锁屏准时通知；通知提交成功不等于横幅或声音成功。
- 浏览器真实文件导出/选取导入往返未手动完成；事务预览与导入确认已用自动化测试验证。
- 下载发起时间无法证明文件落盘；浏览器内数据不替代外部备份。
- 预览借助实际事务回滚，不持久提交；提交时再次使用同一校验，冲突整批拒绝，不相加钱包。
