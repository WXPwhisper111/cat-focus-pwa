# 猫咪名称同步与抚摸反馈

日期：2026-10-22。

## 实现

- 专注页顶部与准备、专注、暂停文案使用当前主陪猫名称；无领养时保留通用空状态。
- 行动猫卡片右上角增加独立“改名”按钮，不嵌套在选择按钮中。名称去首尾空格，1–12 Unicode 字符，允许重名，拒绝空白和控制字符。安全文本/HTML 转义渲染。
- 名称按稳定猫咪 ID 存在 settings.catNames；不修改资源定义、ID、领养、入住、主陪猫或动作。
- 小屋卡片/名字标签、互动目标、换猫窗、统计图像替代文字、商城和欢迎文案统一使用显示名。存活中的播放器只刷新替代文字，不重建播放循环。
- 备份 v8 增加可选 catNames，数据库仍 v6。旧备份不清空名称；合并导入时本机已有自定义名称优先。校验名称、已知 ID 和备份所有权，仍使用原有整批事务与冲突规则。
- 奶油色爱心对话气泡仅在实际 pet:once 播放开始时出现。心形单次轻跳，完成后停留 400ms 并淡出160ms；中断、隐藏和销毁立即清理。每猫独立，不阻挡点击，无额外 RAF。靠近右边缘时向左避让，并按标签宽度保持间距。

## 修改文件与职责

- src/cat-names.ts：显示名解析、验证和当前页面名称缓存。
- src/cat-rename.ts：改名对话框、保存防重和错误反馈。
- src/storage.ts、src/domain.ts：名称持久化与可选备份字段。
- src/main.ts：读取名称、专注文案、行动猫卡片和改名入口；保存后刷新及广播。
- src/cat-player.ts、src/focus-cat.ts：实际播放生命周期通知、无重播的名称刷新。
- src/cat-pet-feedback.ts、src/room-scene.ts、src/room-scene.css：气泡、位置、样式和清理；场景名称刷新。
- src/companion-picker.ts、src/cat-adoption.ts、src/statistics-view.ts、src/room-interaction.ts、src/room-interaction-panel.ts、src/shop.ts、src/daily-welcome.ts：统一显示名称。
- tests/cat-names.test.ts、tests/cat-rename.test.ts、tests/cat-pet-feedback.test.ts：新增6项测试。
