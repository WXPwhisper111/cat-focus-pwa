# 三只猫动画 V2：自然且明显版

本批仅交付独立美术资源与检查页，不替换应用资源、不修改业务逻辑。资源位于 `public/cat-animation-v2/`，旧版全部保留。

## 正式形象与动作

| 素材目录 | 锁定形象 | 保留特征 |
|---|---|---|
| cat-01 | 橘白短毛 V4 | 最大体型、相对小头、短毛、自然尾根 |
| cat-02 | 灰白长毛第二版 | 蓝眼、较收敛的眼形、深色爪子 |
| cat-03 | 淡黄色长毛第二版 | 最小体型、淡毛色、嘴周不对称黄斑 |

idle：63 帧、9260 ms，每轮三次呼吸；胸腹轮廓扩张，头部最多跟随 10 原图像素，脚底和尾根固定。2200–4200 ms 安排一次缓慢尾尖动作，峰值参数 56 原图像素。眨眼在 6600 ms 开始，半闭 80 ms、全闭 100 ms、半闭 80 ms；其余帧 150 ms。每轮一次眨眼，频率不变。

sleep_loop：32 帧、4800 ms，每帧 150 ms，每轮一次胸背呼吸；本次峰值上升参数从 52 降为 32 原图像素（减少约 38.46%），呼吸曲线与形变范围不变，头、前爪、尾巴固定。idle 所有帧图、移动图、动画预览与播放时长均逐字节保留。

ImageGen 为三只猫分别制作了待机与睡觉的动作参考稿，存放在各猫 `motion-design-references/`。这些稿件用于参考动作关系；最终帧图沿用正式素材像素，通过固定支点和局部轮廓位移生成中间帧，避免生成式逐帧重画导致毛色与脸部花纹闪烁。没有对整只猫进行整体上下移动或整图缩放。

## 文件与播放清单

每猫包含 63 张 idle PNG、32 张 sleep_loop PNG，以及对应的 95 张移动 WebP；三猫合计 285 张 PNG 与 285 张 WebP。

- 原图：1254 × 1254，RGBA 真透明，脚底锚点 `[627,1200]`；所有帧保持同一画布，未单独裁切、居中或缩放。
- 移动衍生图：288 × 288，最近邻缩小、无损 WebP，保留透明度。
- `animations.json`：沿用 `canvas`、`feetAnchor`、`animations`、`frames`、`file`、`durationMs` 结构；新增 `mobileFile` 指向移动图。按逐帧 `durationMs` 播放，勿固定帧率覆盖眨眼时长。
- `index.json`：三猫清单。
- 每猫预览：`art/cat-animation-v2/cat-0X/idle-preview.png` 与 `sleep_loop-preview.png` 是 384 像素 APNG；另有 288 像素 APNG 与无损动画 WebP。

原图坐标中的脚底锚点必须按显示比例整体换算。移动图对应锚点为 `[144,275.598086]`；不能将原图锚点 1200 当成移动图坐标。

## 实尺检查

打开独立 `preview.html` 检查页，通过本地 HTTP 服务访问。可选择三猫、待机/睡觉、房间/专注卡/放大，以及旧版对照。页面沿用当前房间布局与专注卡样式；旧橘白对照使用上一批 V4 动画素材。

| 手机视口 | 房间实际宽度 | 猫画布宽度 | idle 轮廓位移 | sleep 轮廓位移 |
|---|---:|---:|---:|---:|
| 390 px | 348 px | 48.94 px | 约 2.04 CSS px | 约 1.36 CSS px |
| 430 px | 388 px | 54.56 px | 约 2.27 CSS px | 约 1.52 CSS px |

上述位移基于实际 288 像素衍生图的主要呼吸轮廓测量。原图 idle 胸侧轮廓测得约 49–52 px，sleep 背部 32 px。sleep 原图比例投影为约 1.25 / 1.39 CSS px；最近邻缩小的像素取整使实际移动图轮廓测得约 1.36 / 1.52 CSS px。专注卡猫画布为 176 px。此次取消此前 sleep 至少 2 CSS px 的验收门槛，以降低峰值、保留自然可辨认的呼吸为准。

浏览器中三猫、两种动作在两种视口下分别完成至少两轮连续播放，检查页无资源加载错误，并保存 24 张峰谷实尺对照截图。检查结果位于 `browser-qa/playback-report.json` 与每猫 `validation.json`。还检查了关键姿态的轮廓、尾部连接和缩小后的辨识度；最终自然感可在检查页继续人工审阅。

逐帧验证包括：画布与 Alpha、物体未触边裁切、脚底稳定、sleep 头爪尾固定、移动 WebP 解码像素无损、APNG 周期时长、清单文件存在及眨眼时长。原有代码和猫资源通过 SHA-256 对比确认未改动。循环末帧回到首帧的主要轮廓变化不超过 1 原图像素。

## 素材包

`packages/` 提供每猫完整包、三猫完整包，以及较小的三猫移动包。完整包包括原始 PNG、移动 WebP、播放清单和动画预览。移动包只包含 WebP 与对应 `animations-mobile.json`，该清单已换算为 288 画布和移动锚点，帧顺序及时长完全相同。

## 复现

在项目目录运行以下脚本；图像脚本需要 Pillow 和 NumPy，浏览器检查需要 Playwright 与 Chrome：

1. `art/cat-animation-v2/build.py`：生成原图、移动图、清单和局部检查报告。
2. `art/cat-animation-v2/prepare_preview.py`：准备旧版移动对照和检查页数据。
3. `art/cat-animation-v2/review.cjs --serve`：运行两轮播放检查、保存截图并保留本地预览服务。
4. `art/cat-animation-v2/package.py`：验证清单、循环接缝、保护文件并制作素材包。

ImageGen 参考图及提示词已经归档；重新生成无需更改正式形象。新资源尚未接入应用。

本次仅缩短既有动作幅度，执行 `reduce_sleep.py` 只重新导出 sleep，并校验 idle 文件 SHA-256 与时间清单未改变。修订报告存放在 `sleep-amplitude-32/revision-validation.json`；该目录还保留修订前 52 px 的睡眠预览和峰值图，方便对照。此调整不需要重新绘制关键姿态。
