# 手机操作与小屋商城焕新 · 验收记录

## 实现与文件

- `src/category-manager.ts`、`src/focus-task-list.ts`、`src/cat-rename.ts`：打开时将焦点放在关闭/取消按钮，任务编辑先聚焦非输入容器；主动点击字段才聚焦输入。正在编辑的草稿和光标恢复机制保留，改名后可恢复到重新渲染的原入口。
- `src/storage.ts`、`src/category-manager.css`、`src/main.ts`：类别删除使用既有归档字段，确认后从选择/管理列表隐藏；同名添加恢复原身份，保留历史与运行中快照、最后类别保护。管理按钮与选择器同行。数据库 v6、JSON 备份 v9 不变，旧备份合并不覆盖本机删除状态。
- `src/category-icons.ts`、`src/daily-welcome.ts`、`src/statistics-view.ts`、`src/focus-ending.ts`：货币展示采用新绘制的线性猫耳/爪印硬币 SVG；普通猫爪图标保留。
- `src/mobile-controls.css`：针对交互元素设置透明的浏览器触摸高亮；保留文字选择、原生输入及暖橙色键盘 focus-visible。原样式没有覆盖 WebKit/Blink 默认触摸高亮，因此它是蓝框的可能来源；没有真实问题手机的调试证据，不能宣称确定所有蓝框来源或系统选区都已消失。
- `src/shop.ts`、`src/cat-shop.ts`：四区分类和每款 10 币的四个升级商品，餐具为双盆套装；购买沿用原事务并自动装备，已拥有家具可免费切换。付费家具库存必须具有匹配的购买记录。
- `src/shop-news.ts`：按商品 ID 保存本来源已查看清单，本轮只显示家具上新；查看对应分类清除，未来新猫和新家具分别提示。可选存储失败不影响购买，禁用存储时刷新后的去重不作保证。
- `src/room-furnishings.ts`、`src/room-scene.ts`、`src/room-behavior.ts`：装备快照决定图层和行为可用性；升级猫窝睡觉目标上移 12 个逻辑像素，其他接触点和基础款不变。装备快照变化清理旧场景任务后重建，防止保留旧家具动作占用；正常同装备渲染不重建。
- `src/room-curtains.ts`：一条可取消环境 RAF、真实 48×125ms 时长、只预加载下一帧；后台/切页/销毁清理，减少动态效果或加载错误回退静态窗帘。猫咪继续使用原播放器与行为执行器。
- `scripts/export-room-upgrades.py`、`public/room-upgrades-v1/`：从归档的正式无损 WebP 导出五件家具、盆栽及 576×416 窗帘衍生帧，按内容哈希识别相同帧，时间位置和时长保留。
- `scripts/generate-sw.mjs`：用新清单明确选取运行资源并加入原有可选媒体机制；沿用现有缓存/更新策略和 100MB 构建门禁。`release-notes.json` 维护五条本轮用户说明。
- 测试改动：`tests/room-upgrades.test.ts` 新增；`categories/category-ui/shop/shop-ui/room-behavior/distribution` 等测试补充行为及相应新预期；`adoption-ui/house-ui` 明确区分猫咪播放器与新增的一条窗帘环境任务，仍检查离页任务归零；统计图标断言改为货币图标。未删除已有测试。

## 实际验证

- 全量测试 63 个文件、309 项通过；类型检查及生产构建通过，差异检查按仓库 CRLF 设置执行。首轮旧断言涉及自动聚焦、停用恢复、整页四区陈列及仅有猫咪 RAF，已按新需求调整并保留原计时/持久化/清理验证。
- 六只猫×基础/升级家具×吃饭/喝水/抓挠/睡觉共 48 种执行闭环，验证正确猫咪资源、循环完成、睡眠位置和锚点释放；现有传送打断、交接、附近待机和自主行为测试继续通过。
- 四商品合计准确扣 40 币、跨标签重复购买只扣一次、余额不足、免费装备切换、存储失败时付款和库存原子回滚、v9 备份恢复及旧备份类别合并通过。
- `browser-results.json`：隔离无头 Edge，320×690、360×740、390×844、430×860、844×390 横屏。实际操作覆盖类别删除重加、清单编辑、改名、测试专注结算、四款购买、装备切换、提示去重、窗帘运动/减少动态效果、刷新恢复、无横向溢出、触摸高亮透明及键盘焦点仍可见。
- 浏览器测试使用独立临时资料；仅在该测试页面临时推进 Date.now，经真实结算流程赚取测试币，没有修改用户存档或应用奖励算法。
- `offline-results.json`：898 项媒体全部缓存，零缺失；离线刷新、背景解码、导航、计时开始/暂停/继续通过。窗帘及升级家具地址包含在缓存清单中。
- `update-results.json`：复用既有隔离测试页模拟发现新版，实际读取本轮更新说明；320px 下五条内容与按钮可用，点击外部不关闭、稍后可关闭。签到/活动会话优先及去重由原有更新测试覆盖；模拟不等同于真实手机旧版升级测试。
