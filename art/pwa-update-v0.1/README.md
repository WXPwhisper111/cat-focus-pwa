# PWA 更新可靠性 V0.1 验收报告

## 实现范围

复用现有原生DOM/TypeScript页面，不修改IndexedDB schema、数据库v6、备份v8、计时算法、任务或经济规则。不增加依赖。

### 文件职责

- scripts/generate-sw.mjs：生成按实际字节计算的资源完整性清单、核心/素材两层清单和版本号。
- scripts/sw-runtime.js：核心安装、版本缓存、内容校验复用、按需加载、分批素材补齐及状态消息；只操作Cache Storage，不访问IndexedDB。
- src/app-update.ts：单例更新控制器、60秒自动检查节流、手动检查、可取消消息通道、素材重试和安全刷新。
- src/app-update-view.ts / src/app-update.css：设置页更新卡片、真实下载数量、正常布局流中的新版提示。
- src/main.ts：挂载独立更新UI并替换原来仅注册SW的代码，不重建其他模块。
- tests/app-update.test.ts、app-update-view.test.ts、app-update-storage.test.ts、update-worker.test.ts：新增14项更新与回归测试。
- scripts/update-qa.mjs：可复现的本地A/B版本故障演练，构建与控制文件生成在项目外的独立目录，不进入正式应用。

## 缓存与更新规则

最终构建版本60ea4a22c712：核心8个文件约0.79MiB；素材507个文件约28.84MiB。原来需要全部515个文件成功才能更新；现在只等待核心完整缓存。

核心下载成功后新SW接管，但不重载任何现有页面。当前页面的JS继续运行，只有用户确认才刷新。首次旧版客户端没有提示代码，仍可能需要联网打开后关闭相关页面再重新打开，不能远程强制所有旧页面立即显示新版。

所有缓存按构建版本隔离，下载启用SRI完整性验证。旧缓存中的同路径文件只有字节哈希与新清单一致才复用，避免把旧图误当新图。保留旧版缓存和旧客户端仍需的哈希JS/CSS；只有当前素材全部就绪且所有相关窗口已报告版本后，才清理更旧缓存，至少保留当前及上一代。

素材每批3个、最多3个并发，每文件最多3次尝试，20秒超时覆盖完整响应体。已下载的文件保留，后续继续缺失文件；后台不发起下一批。失败可手动重试，也可在联网/回到前台时继续。SW或页面被系统结束后，以已落盘缓存为准恢复，不承诺浏览器持续后台下载。

启动及返回前台检查更新，自动检查间隔至少60秒；手动检查与网络恢复可重试，不新增轮询。register使用updateViaCache:none。新版接管时取消旧消息请求，命令回包按版本隔离，防止旧回调覆盖新状态。

用户点击刷新前两次读取当前IndexedDB会话，运行或暂停均拒绝；存在结算/其他弹窗也拒绝。其他标签页不被强制刷新。素材失败不阻塞新版核心使用，也不清除本地记录。

## 真实浏览器A→B演练

隔离来源http://127.0.0.1:4218/，没有操作用户原站点或4195数据。A为当前应用UI配旧的整包缓存SW（从bcefb94读取）；B为同一真实应用构建，改变入口文件名及一个测试素材字节以模拟发布。此演练验证旧SW缓存升级，不代表手机旧版UI已做实机验证。

1. 通过UI新增任务“升级后仍保留这项任务”，设为目标，开始正计时并暂停。
2. 切换测试服务器到B并人为让一张素材返回503。新版核心就绪，页面仍运行A入口，没有自动刷新；更新按钮显示“专注结束后更新”。
3. 素材显示506/507和重试提示，新版就绪不受该失败阻塞。解除503后点重试，达到507/507。
4. 回专注页，原任务及暂停状态保持；继续专注、结束并保存36秒，正常出现结算，不自动勾选任务。
5. 关闭结算后点“立即更新”，只此时加载B入口index-qa-version-b.js，新版提示消失。B测试版本153210545f09，素材完整状态保留。
6. 测试服务器切为全断网（所有请求断开连接），刷新仍正常打开B；统计保留有效时长，清单保留原未完成任务。
7. 断网状态从UI领养喵呜，房间图层和idle加载，手动抚摸pet:once帧2正常播放；DOM检查损坏图片0，场景比例约4:3。
8. 390px及320×568模拟视口无横向溢出；320px页面可用宽和滚动宽均305px。截图为模拟视口，不是手机实机。

演练中发现旧SW不支持新状态协议时的挂起请求问题，已修复版本接管时取消旧查询，并补了旧回包竞态测试。最后收紧了旧缓存清理条件，由最终VM测试覆盖；最终SW字节与B测试夹具版本号不同。

## 实机待验与限制

- Android Chrome主屏幕安装、iOS Safari主屏幕应用、系统回收、真实弱网/限额/存储驱逐未实测。
- 真实多标签页并发操作未人工复测，已做控制器、双DB连接与客户端缓存保留模拟测试。
- 手机存储不足、网络阻断或浏览器终止后台任务仍可能使素材未完整下载；界面如实显示，不承诺所有素材总能自动下载完。
- 首轮迁移旧页面可能需要关闭所有相关窗口再重开；不得通过清理网站数据或卸载来强制更新，避免丢失IndexedDB。
- 不支持Service Worker的环境只能在线使用，设置中显示对应提示。
