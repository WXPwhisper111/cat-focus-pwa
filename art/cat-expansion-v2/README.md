# 新三只猫 V2 · 可播放校准版

本批为黑猫、珍珠、简州狸花白各六组动作。原始帧和手机帧统一在本目录 resources/ 下，未放入 public，避免被现有应用的离线缓存自动收录。它是供实际观感复核的候选素材，未接入应用、未替换 V1 或前三只猫。

## 查看效果

直接打开 motion-reel.webp 可依次观看三只猫的六组动作总览。

- 用本机 Chrome 或 Edge 打开 `gallery.html`：三猫六动作并排播放，并链接到 390、430 像素房间动画。
- 打开 `preview.html`：选择猫与动作、暂停、逐帧检查、重播、V1 对照与接触点。
- 也可直接打开 `card-previews/`、`room-previews/` 中的动画 WebP；它们不依赖网页或本地服务器。
- 可选本地服务：在项目根目录运行 `python art/cat-expansion-v2/serve_preview.py`，然后访问输出的 127.0.0.1 地址。服务只绑定本机并限制可读取文件。

## 格式和动作

共 18 段、537 张原始 PNG、537 张手机帧，另有 36 份房间动画、18 份专注卡动画及 20.76 秒三猫总览。

全部帧为 1254 × 1254 真透明 PNG，手机衍生帧为 288 × 288 无损透明 WebP。画布固定，逻辑脚底基准 [627,1200]；同动作只对源姿态做一次整体配准，不逐帧裁切、居中或缩放。

| 动作 | 帧数 | 周期 | 播放 |
| --- | ---: | ---: | --- |
| 待机 | 63 | 9.26 秒 | 循环 |
| 睡觉 | 32 | 4.8 秒 | 循环 |
| 进食 | 16 | 1.6 秒 | 循环 |
| 喝水 | 20 | 1.5 秒 | 循环 |
| 磨爪 | 24 | 1.2 秒 | 循环 |
| 抚摸反馈 | 24 | 2.4 秒 | 单次 |

待机保持半闭 80 ms、全闭 100 ms、半闭 80 ms 的一次眨眼；轻蹭、尾尖和前爪使用固定关节的刚性转动。睡眠采用上背部局部图层及毛发内部接缝过渡，头、前爪与尾巴保持固定，避免长毛轮廓被逐列拉长。吃饭与喝水使用新俯身姿态，分别编排咀嚼和舔水，身体及脸部花纹固定。磨爪改为两前爪交替动作，后脚固定。抚摸首尾与本版待机首帧逐像素相同。

清单沿用 `frames[].file`、`mobileFile`、`durationMs`、`loop`、画布和锚点结构。吃喝记录嘴部接触点；磨爪另记录逐帧双前爪接触位置，坐标属于 1254 原图画布，朝右。换算为任意显示矩形时，使用 x + px × width / 1254、y + py × height / 1254。接触标记和家具仅在独立预览中出现。

## 源文件与重建

`sources/` 归档正式原型、睡姿、新进食／磨爪姿态及闭眼补丁，`production.json` 记录生成方式、提示词与内容哈希。吸气重绘试验作为参考归档；最终固定部位直接复用同一底图，不把整张 AI 重绘在循环中交替播放。编码按内容哈希复用编码结果，输出仍保留每个时间位置的独立帧文件。

依赖版本见 `requirements.txt`。在项目根目录依次执行：

```text
python art/cat-expansion-v2/build.py
python art/cat-expansion-v2/validate.py
python art/cat-expansion-v2/render_review.py
python art/cat-expansion-v2/validate_previews.py
node art/cat-expansion-v2/check_preview.cjs
python art/cat-expansion-v2/package.py
```

调单动作可使用 `build.py --cat cat-04 --action sleep`，随后重新生成校验与预览。单猫包用于独立使用；完整重建和全量验证使用三猫总包或原项目。手机轻量包只带 mobileFile 对应帧；原 PNG 路径需在完整包中读取。ZIP 留在本地 packages/，Git 不纳入大型 ZIP。

## 验证与限制

逐帧验证图片解码、Alpha、尺寸、时长、固定部位、抚摸首尾和手机 WebP 无损一致性；输出见 validation/。播放控制器测试在 Node 中按清单模拟循环两轮、单次完成与重播、快速切换、加载失败重试和页面隐藏恢复，测试不等同于浏览器视觉验收。

已检查三猫关键相位图及既定房间布局的实尺渲染。房间渲染按现有应用的独立图片图层进行一次缩放，避免先缩到逻辑房间再缩到屏幕而丢失口部动作；72 份动画容器的真实时长、循环标记及缩小后的帧变化均已校验。390、430 为导出图像像素尺寸，176 为专注卡渲染像素尺寸，均为电脑制作预览，未声称手机真机实测。本机浏览器实播已覆盖三猫 18 段：黑猫与狸花白使用 390 像素模拟视口，珍珠使用 430 像素模拟视口；循环段播放两轮以上，抚摸完成后再次重播，并核对末帧回到待机首姿。日志见 validation/browser-playback.json，浏览器无控制台错误。早期本机回环连接受沙箱限制的问题已解决。以上是电脑模拟检查，仍未进行手机真机实测。
