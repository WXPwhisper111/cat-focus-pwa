# V0.3 阶段1：统一交互系统底座

日期：2026-10-21。阶段1完成后停止，未进入动作开发阶段。

## 完成内容

- 三只入住猫各有透明可访问按钮；点击显示选中圈、名字和场景下方交互面板。
- 当前互动对象独立于主陪伴猫。点击场景猫不保存主陪伴选择，不改变所有权、入住或钱包。
- 开启猫窝、食盆、水盆、地毯、猫抓板五个家具热点；窗帘保持不启用。
- 未选猫点击家具时，面板列出入住猫供选择；选定后保留家具目标。直接点击另一只场景猫时清除原家具目标，展示该猫完整行为列表。
- 五种行为入口均禁用并显示未开放说明；没有动作预演、移动、奖励或属性变化。
- 集中控制器校验入住、目标及行为匹配，支持单猫互斥、完成恢复和取消。可注入执行器供后续实现和自动化测试；生产没有注入执行器，所以不会实际执行任何行为。
- 选择不等于行为：选中信息独立保存，每只猫各有idle/acting/recovering逻辑状态；当前生产均保持idle。

## 坐标、命中与生命周期

继续使用原1024×768布局和4:3比例。家具热点由对应家具矩形与局部可见区域比例推导，不再另写全局家具热点坐标；猫咪按钮从当前校准站位推导。图片顺序、站位、阴影和昼夜叠层保持原实现。

透明按钮至少44×44 CSS像素。鼠标/触屏点击时，猫身体命中优先于地毯；实际物体范围优先于其他按钮的扩展范围。仅命中多个扩展范围时打开明确候选选择，而不是选最上层家具。键盘Enter/空格直接选择当前聚焦按钮。按钮不阻止原生竖向滚动。

临时状态只在小屋内存中存在：普通页面刷新通知或主陪伴切换造成的场景重建，通过稳定猫ID保留当前选择；离开小屋销毁控制器与面板，取消任务，再次进入未选中。原房间继续负责动画、前后台和昼夜清理。

数据库仍v5，备份仍v6。没有新增存储字段、修改货币或经验规则；互动不调用任何购买、签到或会话结算接口。

## 尚未验证 / 素材缺口

- Android、iPhone真机触控、真实手指滑动与系统回收：**未实测**。电脑窄屏和鼠标/键盘操作不能代替它们。
- 扩展范围歧义分支由几何自动化测试覆盖，未以手机手指实测。
- 不新增美术；目前只有真实idle与sleep_loop。抚摸、吃饭、喝水、抓挠、行走及睡下/起身过渡尚未接入，未用占位动画冒充。
- 原有家具遮挡和固定站位没有扩展为移动系统。后续到功能区执行行为时，仍需实现位置、接触点与遮挡校准。
- 没有亲密度、属性衰减、货币奖励、自主行为或家具装备替换。
