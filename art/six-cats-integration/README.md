## 资源

- 使用 cat-expansion-v2，cat-04 吉吉、cat-05 珍珠、cat-06 铃铛；前三只猫稳定 ID、默认名称及源素材不变。
- 实际核对 18 段 / 537 个帧位置：每猫 idle 63、sleep 32、eat 16、drink 20、scratch 24、pet 24。
- 每猫循环长度分别 9260 / 4800 / 1600 / 1500 / 1200ms；pet 单次 2400ms。保留逐帧时长和重复时间位置。
- 537 张原始 PNG：438,148,584 字节；原始移动 WebP：22,813,416 字节；内容哈希去重后 225 张：9,999,016 字节（约减少 56.2%）。
- Pillow 实际解码全部 PNG 和 WebP，验证 1254×1254 / 288×288、RGBA、透明和不透明像素。核对 pet 首尾与 idle 起帧一致、loop 标志、帧时长总和与逐帧双爪接触点。循环首末帧平均通道差最大 0.0431/255，仅作为接缝诊断，不能代替手机观感验收。
- 嘴部 / 双爪接触位置与脚底锚点分开处理；双爪逐帧数据保留为元数据，不驱动整只猫逐帧位移。源 sleep 映射 sleep_loop，不生成 enter/exit。
- 只导出哈希 WebP 和三份必要清单。构建输出去除新猫旧版公开目录，原文件和 V1 归档保留；新资源 228 个文件进入现有媒体缓存清单。
- 可重跑 `scripts/prepare-cat-expansion.py`（Python + Pillow）；精确清单见 resource-audit.json。

## 功能与数据兼容

- 六选一首次领养；老存档在 settings 中原子建立一次额外资格，只能免费领取新增三猫之一。新用户没有额外资格。
- 免费领取记录独立于付费流水，跨数据库连接事务去重。满员购买/领取只解锁，不替换居民，不改变主陪伴猫；其余猫每只 80 币。
- 小屋管理支持入住、暂离和满员替换，保留 1–3 位居民。移出前安全结束该猫任务；存储失败不修改名单。未移出的播放器与站位保留。
- 名称、主陪伴、行动猫独立；行动猫离开后优先选择已入住主陪伴，否则选择第一位居民。
- IndexedDB 仍 v6，无新对象仓库；JSON 备份 v9，继续接受 1–8。旧备份首次恢复到新设备时识别旧用户；本地已领取记录不因重复旧备份再发放；v9 领取冲突整批拒绝。
- 无账号级身份：清空存储或不同设备不能验证是同一个人。新版六猫存档不能由只认识三猫的旧客户端读取，应使用新版应用恢复。

## 行为与位置

- 自然结束家具行为：实际离开交互位后释放锁，在家具相对候选点 idle；无安全位置回自己的地毯。抚摸原地结束。
- 替换指令：旧动作退出、清理后直接前往新目标，不插入待机传送；让位、取消、主动返回和错误回默认地毯。
- 附近点检查其他猫、预留目标、交互锁、默认地毯和边界；实际位置阻挡新目标时也先让位。
- 保留 150ms 淡出 / 180ms 淡入，在完全透明的完成事件处确认最新可用目的地。已淡入则完成可见过渡再处理后续指令；取消或失效目标不在透明处无限等待。
- 恢复阶段仍属于当前任务，防止自主调度抢占；刷新重建回默认地毯，不恢复临时动作、占用、透明度或帧索引。
