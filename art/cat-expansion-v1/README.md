# 新三只猫完整动作素材 V1

本批包含黑猫（cat-04）、珍珠（cat-05）、狸花白简州猫（cat-06）各六种动作：待机、睡觉、进食、喝水、磨爪、抚摸反馈。素材独立存放于 `public/cat-expansion-v1/`，没有替换前三只猫的素材，也没有接入应用逻辑。

每帧画布固定为 1254 × 1254 真透明 PNG，脚底/身体接触锚点 `[627,1200]`；每帧附 288 × 288 无损透明 WebP。清单 `cat-XX/animations.json` 记录逐帧 `durationMs`、循环属性、朝向与接触点。动作不含家具、地面阴影、文字或 UI。

| 动作 | 帧数 | 单轮时长 | 类型 |
| --- | ---: | ---: | --- |
| 待机 | 63 | 9.26 秒 | 循环，含一次慢眨眼 |
| 睡觉 | 32 | 4.8 秒 | 循环，平缓呼吸 |
| 进食 | 16 | 2.4 秒 | 循环，右向俯身 |
| 喝水 | 20 | 3 秒 | 循环，右向俯身与舔水 |
| 磨爪 | 16 | 1.92 秒 | 循环，右向抬爪 |
| 抚摸反馈 | 16 | 2.4 秒 | 单次，首尾回待机 |

接触点记录于进食、喝水、磨爪的 `contact` 字段。它们是独立预览的物品对齐参考，实际摆放时可根据房间尺寸等比换算。跨功能区的淡出换位与前一批 V2 规则一致，本包只提供动作素材。

`art/cat-expansion-v1/preview.html` 可在静态文件服务中查看动画，`contact-sheet.png` 提供六动作三猫对照。`packages/` 有三份单猫包、三猫总包和手机轻量包。制作所用关键姿态保存在 `keyposes/`，`build.py` 可重新生成逐帧资源。
