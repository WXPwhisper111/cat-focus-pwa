# 发布资源精简验收（2026-10-24）

## 范围与保护

- 只精简新生成的 `dist`，不删除 `public`、`art`、Git 历史或 Vercel 历史部署。
- `scripts/finalize-distribution.mjs` 复用现有离线资源清单，先核验路径、完整性和体积，再逐个移除未列入清单的生成文件；拒绝符号链接、越界路径和校验失败。没有递归删除。
- 清单内资源加 Service Worker 超过 100,000,000 字节时构建失败，避免静默发布大包。
- `package.json` 在原有构建末尾调用该脚本；缓存策略和业务代码不变。
- `release-notes.json` 更新用户可读说明，继续使用现有更新弹窗。
