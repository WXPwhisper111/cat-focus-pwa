## 数据与兼容方案

数据库保持 **v5**，商城使用已有 settings，不为商城单独升级数据库；钱包、流水、购买和猫咪状态仍在跨存储事务内提交。

现有导入属于**记录合并 + 受冲突保护的经济状态恢复**，不覆盖整库，不直接把两个余额相加。备份升级至 **v6**，包含：

- 类别、有效专注记录、由记录计算的经验/等级校验信息。
- 独立钱包、收入/支出流水、专注结算凭据、余量和迁移边界。
- 完整每日签到日期、领取时间、奖励数及交易 ID，与签到流水交叉校验。
- 所有权、入住、主陪伴猫、购买记录、基础家具所有权和四区装备槽。
- 数据库、钱包、商城和成长算法版本标识。

兼容规则：

1. v1–v4不带独立钱包的文件仅合并记录，不清空现有新币、不兑换历史时长。历史记录仍贡献原有经验。
2. v5继续验证并恢复独立钱包；v6增加商城、签到及成长的一致性校验。
3. 钱包只能恢复到无专注结算凭据、无消费、无累计零头的本机经济状态，或重复导入相同状态。首次启动自动获得的未消费签到奖励按日期/交易 ID 去重保留，避免首日奖励阻碍恢复；不是任意钱包加总。
4. 旧文件无签到信息时不会删除本机历史。新文件与本机签到日期去重，反复导入不能再次领取同一天的奖励。
5. 钱包、商城、猫咪或记录冲突则整批回滚。沿用此前确认的猫咪状态冲突拒绝规则，不借导入隐式换猫。已有消费后不支持用较旧快照倒退余额。
6. 活动会话和本机其他设置不进入备份；存在活动会话时不恢复不同经济快照。导入不是多设备同步工具。

## 未实测与限制

- **Android、iPhone真机布局、主屏幕安装、后台系统回收、真实锁屏及长期离线：未实测**。电脑窄屏与停服缓存测试不能代替它们。
- 本地签到使用设备日期，不联网校时或防篡改；备份严格校验结构和内部一致性，但不是加密签名或在线防作弊系统。
- 备份冲突时需要用户保留原文件、选择正确恢复目标，当前没有分支合并或经济冲突解决界面。
- 当前只提供三猫固定站位；没有自由行走、吃喝互动、家具更换或付费家具。未新增美术素材。
- 旧数据库升级由自动测试创建旧库验证；未对用户实际旧数据库执行破坏性升级演练。
