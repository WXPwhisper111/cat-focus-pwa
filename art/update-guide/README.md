# 更新指引与此前本地改动整合

## 实现
复用现有文档流更新横幅作为非阻塞引导，不增加第二套弹窗队列。检测到与当前页面不同的可用版本后显示“发现新版本 / 前往更新”；签到待展示、签到欢迎及其他模态框打开、完成总结待确认或页面不可见时延后显示。使用 open 属性观察与 close/visibilitychange 事件刷新显示，不增加轮询；销毁时移除观察与监听。

点击后切换设置、滚动并聚焦更新区域，再调用现有安全 apply；重复点击防重。暂停或运行中的会话仍由两次数据库检查保护，不刷新；操作失败保留原因和重试入口。点击指引表示本次更新授权，不在用户未点击时自动重载。用 #settings-update 保持更新后落在设置；用户切换其他导航即清理该标记。数据库、备份和经济规则不变。

修改：src/app-update-view.ts、src/main.ts、tests/app-update-view.test.ts。
