# 阶段 B：首次领养与猫咪配置化

验证日期：2026-10-20。仅实施本阶段；没有商城、自由移动、家具交互、多猫管理或换猫入口。

## 实现与文件

- `src/cat-definition.ts`：稳定 ID、名称、介绍、预览、画布、脚底锚点及动画资源目录；新增猫时修改配置和资源，不改页面核心逻辑。
- `src/cat-player.ts`：复用动画播放器，支持逐帧时长，保留后台暂停与销毁清理；可选睡眠缺失时仅显示本猫静态 idle 首帧。
- `src/cat-adoption.ts`、`.css`：三张候选卡，只有选中卡动画，确认前只修改临时选择；保存失败可重试。
- `src/cat-house-state.ts`、`src/storage.ts`：验证并保存到现有 settings 的 `catHouse` 键。IndexedDB 仍为 4；并发领养通过同一事务串行检查，禁止后续换猫。
- `src/main.ts`、`src/focus-cat.ts`、`src/room-scene.ts`：主陪伴猫共享配置，各页独立播放器，离开页面销毁。房间图层、家具坐标和脚底校准继续复用。
- `src/domain.ts`、`src/storage.ts`：备份版本 4，可选 `catHouse`，兼容 1–3。导入冲突整批回滚，不隐式换猫；旧备份不清除领养，其他设置仍不导出。
- `scripts/generate-sw.mjs`：缓存全部实际使用的派生帧和房间图层，排除原始大帧目录。

旧用户的计时、记录、类别、累计经验与猫爪币不变。尚未领养时专注页临时显示旧橘白猫，小屋显示首次领养；没有自动分配领养状态。数据损坏时小屋显示读取错误和重试，不自动重置。

状态包含 ownedCatIds、residentCatIds、companionCatId。校验配置 ID、无重复、入住已拥有、最多三只入住、主陪伴猫已拥有；已拥有猫时要求有效主陪伴猫。结构为未来扩展预留，本阶段界面只创建一只猫，并只渲染主陪伴猫。

## 验证结果

### 自动化

91 项测试、18 个测试文件通过；生产构建通过。新增覆盖：状态校验、确认保存及并发、旧记录与活动会话保留、数据库重开仍为 4、版本 1–4 备份兼容、重复导入、冲突与后续记录错误的事务回滚、变帧时长、缺少睡眠资源的安全回退、候选切换与失败重试、跨页同猫与生命周期、全部素材路径和锚点、原始大帧排除缓存。原有计时、统计、奖励、类别与结束流程测试一并运行。

### 实际桌面浏览器

使用独立测试源 127.0.0.1:4190 和 localhost:4190，未修改用户原有 4182 数据：

- 320、390、430 像素视口候选页与房间无横向溢出，房间保持 4:3。
- 候选切换有选中反馈；未确认刷新仍需领养；确认后刷新直接恢复已领养猫。
- 两个隔离源分别领养灰白猫、奶油猫，专注页和小屋显示对应猫；暂停分别加载本猫 sleep_loop，房间始终 idle。
- 反复切换专注、统计、设置、小屋正常；查看控制台未发现错误。循环及监听器无累积由自动化补充验证。
- 停止预览服务后，刷新仍正常打开；小屋图层和动画可用。运行中的正计时恢复为 02:35，结束后保存实际 2 分钟 41 秒，显示 +2 经验、+2 猫爪币，统计显示当日 2 分钟。没有写入伪造历史记录。
- 另一隔离源离线刷新后，仍可进入已领养奶油猫的小屋。
