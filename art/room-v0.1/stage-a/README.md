# 猫咪小屋 V0.1 阶段 A

## 完成内容

- 底部导航为“专注、统计、猫咪小屋、设置”，继续使用现有内存页面切换；正常刷新仍回到专注页。
- 房间移至独立猫咪小屋页面。专注页恢复原来的单猫卡片、接触阴影及陪伴文案，继续正常待机、暂停睡觉。
- 小屋复用 `room-scene.ts`，使用原布局与独立图层，仅显示一只 idle 橘白猫。四区、三个预留站位及脚底锚点配置没有改动，没有启用物品热点。
- 按设备本地时间自动切换：07:00–18:59 白天，其余为夜间。使用既有昼夜窗景；夜间增加 CSS 暗色遮罩及暖色光照层，没有生成或合并任何运行素材。

## 实现与维护

`cat-definition.ts` 提供稳定资源 ID `orange-white`、显示名称及动画配置；它是资源定义，不是入住记录。`cat-player.ts` 从原房间组件提取共用加载、解码、逐帧播放与销毁逻辑；`focus-cat.ts` 只负责原专注卡的 DOM。房间通过每帧回调应用原有脚底偏移，专注卡沿用完整精灵画布。

`main.ts` 在专注页挂载专注播放器，在小屋页挂载房间，同类页面重渲染复用实例，离开后销毁。小屋始终传入 idle，不根据专注暂停状态切换姿态。统计和设置不保留播放器。

房间进入时检查时间，前台每个整分钟重查，`visibilitychange`、`focus`、`pageshow` 返回时立即重查。隐藏、pagehide 及销毁时取消环境定时器；播放器独立取消绘帧任务。切换窗景前等待图片解码，异步旧请求或已销毁组件不会覆盖新环境。

环境状态不进入数据库，也不读取专注时长。数据库仍为版本 4，备份仍为版本 3；计时、结算、统计、经验、猫爪币算法未修改。

## 临时开发预览

运行 `npm run dev`，在终端给出的地址后添加：

- `/?roomPreview=day`
- `/?roomPreview=night`

开发模式下会直接进入小屋，并显示“开发预览”标记；仅当前预览页强制指定环境。生产构建忽略此参数，没有正式用户切换设置，不修改设备时间或本机数据。开发服务不注册 Service Worker，离线检查使用正式构建预览。
