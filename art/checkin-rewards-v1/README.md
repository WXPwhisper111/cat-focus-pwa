# 签到额外奖励与睡眠反馈

## 实现

- `src/checkin-rewards.ts` 集中维护 v1 奖励规则、日历连续性、领取/免补发身份、校验和展示结果。
- `src/storage.ts` 在同一事务中保存基础签到、额外流水、余额与 settings 领取记录。基础流水仍为 5 币；额外流水为 `checkin_bonus`。
- `src/domain.ts` 支持 JSON 备份 v10 和 1—9 版导入；数据库保持 v6。恢复历史不发币，领取/免补发与钱包冲突整批拒绝。
- `src/daily-welcome.ts/css` 在原欢迎弹窗内展示实际到账、明细、连续/累计进度与下一节点；延续签到优先级。
- `src/category-icons.ts` 通过原 `paw-coin` 接口读取 `src/assets/paw_coin.svg`，保留正式素材的 64×64 viewBox、颜色和四趾爪印。
- `src/cat-pet-feedback.ts` 与 `src/room-scene.css` 替换睡眠内容为月亮和两颗星星，延用实际播放器生命周期，不使用爱心跳动动画。
- `release-notes.json` 包含奖励规则、历史免补发及 v10 备份兼容说明。

## 素材来源

正式图标来自项目外原始归档 `D:/MyDesktopPet/artwork/paw-coin-icon-v1/paw_coin.svg`，源 SVG 内容保持一致，仅规范文本换行；PNG、WebP、预览和制作清单保持原归档。发布仅将 SVG 内联进既有脚本，未新增图片下载或素材缓存策略。

## 规则边界

历史已达成节点以 waived 保存；新增日期的节点以 paid 保存。连续节点身份包含起始日期、轮次和第3/7天，累计节点身份包含门槛。时间倒退不发额外奖励；如果补入旧日期会改变已有奖励身份，则拒绝签到并提示校准系统日期，保护已有账目。

本地数据不能验证账号或服务器时间，不提供跨清空存储/设备的防重复领取保证。新版备份需在支持 v10 的客户端恢复，旧版文件仍可导入；存在钱包或领取冲突时整批拒绝。
