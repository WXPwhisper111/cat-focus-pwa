## 新增测试矩阵

### 快照与策略：9 项

- 全部 stores 的键和值、钱包流水与币凭据、猫咪/资格/家具/签到、任务/选择、待展示总结、位置与备份偏好完整保留，源内容哈希不变。
- active 原始值可以被快照捕获，但活动状态阻止迁移激活。
- 坏校验和、坏钱包关联、未知设置、JSON 不支持类型/稀疏数组均拒绝，不自动修复。
- copied 未验证、源变化、目标不匹配、指针变化时分别阻止切换。
- 归属/备份/独立钱包未明确确认时拒绝；离线或未接云时均不开放共享购买。

### 上下文、迁移与恢复：19 项

- 登录/换号本身不打开来源数据或迁移日志；未登录、未允许预览不读源库。
- 明确确认后所有业务行保真，重复同一迁移不重复复制/发奖。
- 预览后源变化、活动计时、缺失源库、旧版本源库均拒绝；不创建空访客库代替，不升级旧 schema。
- 复制事务模拟配额失败：影子业务行整体回滚，重新创建 manager 后可从持久日志/镜像恢复。
- copied/verified 间中断：已有行不重新写入；激活失败指针不变，坏影子内容不清空“修复”。
- A/B 切换、退出、保留的旧 Repository 和同 UID token 刷新：正确撤销/保留能力；B 看不到 A 计划、快照和任务。
- A 未提交任务写入、指针激活事务中切号：事务 abort，不把结果应用给 B。
- 独立钱包默认拒绝替换，明确恢复为新分支时两份钱包不相加；回滚后双方新增数据仍保留并可导出。
- 首次回滚恢复“未归属”，重复回滚幂等，旧结束任务不能重新激活。
- 坏文件恢复无新迁移任务，正常文件恢复无历史补奖；保留分支验证失败则当前指针不变。
- 并发计划由 CAS 指针比较裁决；账号库不能冒充访客源；已归属 A 的源阻止 B 使用此前预览抢领。

### 开发面板与认证联动：4 项

- 明确预览和双重确认后才能激活，换 B 立即清空 A 的摘要和确认状态。
- 过期 getSession 和迟到预览结果不恢复 A 界面。
- 在等待 signOut 前暂停保护上下文，网络退出失败也不继续开放数据访问。
- 初始认证恢复尚未完成时暂停，旧结果不能再次启用数据上下文。

## 测试环境与边界

所有新增数据读写均使用 fake-indexeddb 的独立工厂与可丢弃库，界面使用 jsdom，认证事件为模拟 SDK 接口。原全量回归同时覆盖既有计时、钱包、购买、签到、备份等行为。本轮没有 Android 真机迁移、真实浏览器断电、磁盘故障或大容量配额实测；未把模拟中断称作物理断电验收。

关键残余风险：跨数据库末次检查与切换无法原子；同源 IndexedDB 不是加密安全域；完整镜像为明文且需用户确认外部保存；未知结构/坏账本/坏原分支失败保留、不自动修复；多分支占额外容量且不自动清理；正式账号入口、全部写入口保护、来源转移及云端基线仍待后续实现。
