# V0.2.3｜开发测试页操作与恢复说明

本阶段仅开发页接入，正式 PWA 不启用账号数据库。请先阅读 [设计与残余风险](adr-002-local-data-protection.md)。自动化验收使用隔离数据，不是下面的真实存档手工步骤。

## 启动与准备

```powershell
cd D:\MyDesktopPet\cat-focus-pwa
npm run dev -- --port 5173 --strictPort
```

打开 `http://localhost:5173/auth-test`。Supabase 公开配置沿用 `.env.local`，不在聊天或文档中填写实际密钥。`npm run preview` 和生产构建都不提供此页。

完整镜像需要 Web Crypto，请使用 localhost 或可信 HTTPS；手机普通局域网 HTTP 可能不具备此能力，不能绕过校验。工具不会在登录时自动读取访客存档。

第一次手工试用建议使用单独浏览器配置文件，以可丢弃数据验收。不要把熟悉流程的第一次操作直接用在重要存档上；本次开发没有替用户操作真实数据。

## 明确归属与迁移

1. 先结束源库活动专注、关闭其他 PWA 页面。登录测试账号。
2. 可以只检查账号日志；“账号未归属”是正常安全状态，不会创建空访客数据或自动选择钱包。
3. 点击“我确认读取访客存档，生成迁移预览”。查看 UID、记录/钱包/猫咪/家具/签到数量、影子库名及 SHA-256。任何原始关联错误、未知结构或活动计时都应停住，不做修复。
4. 点击“导出预览的完整快照”，确认文件实际保存，最好另存设备外。此文件格式为 cat-focus-local-migration v1，包含旧 JSON v10 没有的业务状态；不含 Auth 会话。
5. 勾选备份已保存，明确选择该快照的独立钱包；云端基线依然是未配置。默认不勾选替换已有账号分支。
6. 点击确认。系统重新检查源，复制到新影子库、重新验证，最后切换**开发工具**账号上下文；正式访客 PWA 不切换。
7. 点击读取当前账号副本摘要，核对数据数量及余额。相同计划重复确认应不再次发币或重新复制行。

如果目标已有独立钱包，默认拒绝。只有确定需要从当前快照恢复为另一条独立分支时，才勾选“新分支、旧分支归档”；余额不相加，旧分支不覆盖。

## 中断和错误

刷新测试页或重新登录同一 UID 后，点击检查日志，选择本账号的 prepared/copied/verified 任务，读取预览，重新确认备份和经济基线，再继续。已复制的非空副本会比对内容；冲突时不会清空重建。

源变化时请重新预览；配额不足时停止，保留原数据与日志，不要求清空整个站点。缺失源库不会自动生成空库代替。未知版本/字段、坏哈希、坏钱包等报错应先保留材料并审查，不绕过验证。

## 回滚和恢复

检查当前账号上下文，明确勾选回滚确认后执行。原分支验证失败则指针不切换。首次迁移回滚后账号恢复未归属；原访客库仍在。

回滚后的新分支及其新增任务没有删除。通过迁移日志选择对应任务，点击“导出选中分支的最新完整快照”；若以后要取回，用文件选择框读入此完整快照，验证后生成新计划，再确认恢复。文件恢复永远创建新分支，不覆盖现有库。

旧 JSON v10 业务备份不能在此文件框当作完整镜像恢复。原设置页的旧 JSON 导入功能仍保留其原有规则，本阶段没有修改。

## A/B 隔离与退出

- 退出请求发出前先撤销保护上下文；即使退出失败，面板暂时不可读账号数据，刷新后重新核实认证状态。
- 换 B 后，面板清除 A 的摘要、迁移计划、选择和备份确认。B 不能列出/打开 A 的任务和快照，也不能再次认领已归属 A 的访客源。
- 回 A 后可显式检查并读取保留分支。回滚不自动解除访客源的 A 归属；不提供转赠账号功能。
- 该隔离只覆盖开发工具接口；正式 PWA 仍呈现原访客库，浏览器同源存储也没有因 UID 而加密。

本阶段没有共享购买入口或云端签到。即使联网，共享经济购买确认接口也明确不可用，不会在本地冒充服务端成功。不会补发历史签到、专注币、额外奖励或免费资格。
