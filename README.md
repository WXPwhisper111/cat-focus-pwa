# 猫咪专注 PWA

独立于桌面版的手机优先专注工具。沿用等级、周/月统计规则；不读取桌面 SQLite。现已支持三只候选猫的首次领养。

## 当前版本：Focus List V0.1（M1 + M2）

已新增专注清单、目标选择、独立会话快照和完成反馈。计时卡采用浅杏色，清单采用浅鼠尾草色，目标提示窗采用淡金色；手机清单通过抽屉展开。

**当前数据库 v6、JSON 备份 v8，兼容旧 v1–v7 备份。**升级只增加任务仓库，不改变计时和经济规则。以下历史阶段的版本号描述当时交付，最新规则以[Focus List M3 验收报告](art/focus-list-v0.1/m3/README.md)为准。升级前建议备份并关闭旧页面再联网刷新。

## 本地运行

建议使用 Node.js 24，以统一开发、构建与自动测试环境。

```powershell
cd D:\MyDesktopPet\cat-focus-pwa
npm ci
npm run dev
```

如果使用 **CMD（命令提示符）**，进入 D: 盘目录时需要加 `/d`：

```bat
cd /d D:\MyDesktopPet\cat-focus-pwa
npm ci
npm run dev
```

电脑浏览器可访问终端显示的本地地址。正式静态文件由 `npm run build` 生成在 `dist`，用 `npm run preview` 预览。`npm test` 运行自动检查。

## 猫咪小屋与商城（V0.2）

底部导航为“专注、统计、猫咪小屋、设置”。首次进入小屋时，在喵呜、芒果、橘宝中选择一只；只有选中卡片播放动画，确认前不会保存。确认后立即保存领养、入住和主陪伴猫，刷新、重新打开后直接进入小屋。初始猫永久拥有；通过小屋中的猫咪商城购买其他两只，每只80币，自动入住，最多三只。可在已拥有猫咪之间切换主陪伴猫。

专注页和小屋共用同一个主陪伴猫 ID，各自管理动画生命周期；专注运行时 idle、暂停时睡觉，小屋始终 idle。尚未领养时，专注页不显示猫咪，显示提示和“去领养猫咪”按钮；仍可正常使用计时。数据库现为版本 6，XP规则不变，猫爪币按下方M1独立钱包规则结算。三只候选均使用最新 `cat_01／cat_02／cat_03` 真实素材；喵呜已换用新模型及新动作。稳定领养 ID 保持不变，已领养用户不需要重选。统计页右上角及成长头像跟随同一个主陪伴猫，未领养时不显示猫咪图片。猫咪配置允许缺省睡眠动画，此时暂停显示本猫的静态 idle 首帧，不借用其他猫的素材。

小屋复用独立图层和 4:3 布局，按本地时间 07:00–18:59 显示白天，其余时间显示夜景；回到前台重新检查时间。无正式昼夜设置和家具交互。配置、资源生成方法与本轮验收见 [阶段 B 交付记录](art/room-v0.1/stage-b/README.md)；[阶段 A 说明](art/room-v0.1/stage-a/README.md)及[首次房间接入说明](art/room-v0.1/scene-calibration/integration.md)作为历史记录保留。

本次素材与展示更新的验证记录见 [猫咪更新说明](art/room-v0.1/cat-refresh/README.md)。阶段 A、B 原报告描述各自交付时的历史行为，最新行为以本说明为准。

**动作 V2 接入修正**：最新动作实际来自 `public/cat-animation-v2/cat-01～03/mobile`，每猫 idle 63帧／9260ms、sleep_loop 32帧／4800ms；不再播放此前 cat_01～03 的10／8帧动作。运行 `node scripts/index-cat-animation-v2.mjs` 从交付清单更新运行索引，再构建。保留逐帧时长及脚底锚点；生产缓存仅包含285张V2移动帧（约16.52MB），不再缓存旧猫帧或V2大PNG。

## 正计时与倒计时

在专注页选择“倒计时”或“正计时”，应用会记住上次选择。倒计时仍支持 1–180 分钟；正计时从 `00:00` 开始，不需要填写目标时长，也不会自动结束。切换模式时会保留尚未开始的倒计时时长输入。

正计时支持自定义类别、暂停／继续、“结束并保存”和“放弃且不保存”。离开页面或关闭应用后，运行中的正计时仍按时间继续累计；如果要停止累计，请先暂停或结束。刷新、重新打开或返回前台时会恢复当前会话。超过一小时后显示为 `小时:分钟:秒`，正计时不受倒计时 180 分钟上限限制。

结束并保存时，按实际有效时长计入统计和奖励，记录归属手动结束的本地日期；暂停时长不计入。放弃不保存记录，也不发放奖励。两种模式共用唯一活动会话，正在专注时不能切换模式。

## 专注结束体验

倒计时点击“提前结束并保存”后，先显示确认窗口，可选择继续专注或结束保存。确认期间保持原来的运行或暂停状态，不会自动暂停；窗口里的已专注时长会随计时更新。如果此时倒计时到点，会直接正常结算并展示完成总结。正计时的“结束并保存”直接保存并展示总结。

两种模式点击“放弃且不保存”均需确认；取消不改变计时状态。已到点的倒计时会优先保存完成记录，不会被放弃操作丢弃。确认操作只针对打开窗口时的那次专注，不会误结束其他页面新开始的会话。

保存成功后，总结显示类别、计时模式、有效时长和本次获得的经验、猫爪币。XP根据保存前后累计整分钟数的差额计算；猫爪币单独按迁移后每5分钟有效专注累计，分别显示奖励，包含各自跨记录零头；不足一分钟且尚未达到奖励门槛时，会显示 `+0` 和累计说明。没有产生有效时长或确认放弃时，不显示奖励总结。

点击“知道了”关闭总结。未确认的总结保留在本机，刷新或重新打开后仍可查看；多次结算时依次展示。关闭总结不会再次发奖，多页面也不会重复保存记录。总结的查看状态不参与备份，导入历史记录不会弹出奖励总结。保存失败时不会清除活动会话，可以重试。

## 自定义专注类别

类别选择使用暖色自定义菜单，显示图标和选中标记；健身使用哑铃，数学使用数学符号。支持方向键、Home／End、回车、空格、Esc 和点击外部关闭，靠近屏幕底部时向上展开。已有数据库会一次性补充新类别；同名自定义类别保留 ID、记录和停用状态，不重复添加。类别更新不单独升级存储；当前数据库为版本5，备份为版本6。

在专注页“专注类别”旁点击“管理”，输入 1–20 个字符的名称后添加。添加成功会自动选中；更换选择后，刷新或重新打开也会记住上次选择。管理窗口不会清空已填写的专注时长。

英语、计算机、健身和数学是初始类别，所有类别均可停用或恢复，但至少保留一个可用类别。停用后不再出现在新专注的选项里，已经开始的专注和历史记录均保留。输入已停用类别的同名名称时，可点击“恢复并选中”沿用原类别；英文名称不区分大小写判断重复。

本地数据库会自动升级到版本 5，保留历史记录、XP、等级、领养及活动会话；旧猫爪币首次迁移清零，迁移前时长不换新币。如提示升级被其他页面阻挡，请关闭此应用的其他标签页后重新打开。

## 专注统计

统计页默认选择“本周”，可切换今日、本周和本月；本月支持选择历史月份。顶部今日专注、本周累计、连续专注天数始终展示当前真实数据，不随分析范围改变。

- 今日直接展示分类分布，不再重复展示分类时长图；本周趋势展示含今天的最近 7 个自然日，分类分布统计周一至今天；本月趋势按自然周聚合，首尾周只含当月日期，未到日期显示 0。点击柱子或使用键盘回车、空格可查看明细，选中框与聚焦框仅覆盖绘图区，不包含日期。
- 趋势与分类分布隐藏已停用类别，恢复后重新显示；展示可用初始类别及当前范围实际使用的自定义类别。占比分母是可用类别的有效时长，顶部累计、近4周及成长仍包含全部历史，非空数据的取整百分比合计为 100%。
- 连续专注以每天至少一条大于零的已保存记录计一天，同日多次只算一天；今天尚无记录时，从昨天向前回溯。提前保存计入，放弃及运行中会话不计入。
- 记录按保存时的本地结束日期归属，跨午夜不拆分。近 4 周使用周一开始的自然周，可跨月；本周只统计截至今天，其他周显示完整周期。
- 猫咪成长仅在今日显示，位于分类分布上方，经验和猫爪币配有星星、猫爪图标；等级、经验继续使用原有累计算法，猫爪币读取独立钱包可消费余额。自定义类别使用 10 种线条图标，按类别 ID 稳定分配，允许重复；英语和计算机保留书本、电脑图标。统计仅仅读取记录，不修改历史数据、存储格式或备份版本。时长展示取整分钟，不足一分钟显示“少于 1 分钟”，计算仍保留有效秒数。

## 手机安装与 HTTPS

两台手机与电脑连接同一 Wi-Fi。先为电脑的局域网 IP 签发受信任的 HTTPS 证书，并在 Android 和 iPhone 上安装、信任对应根证书。例如用 `mkcert`：

```powershell
mkcert -install
mkcert 192.168.1.10
$env:CAT_FOCUS_TLS_CERT = (Resolve-Path '.\192.168.1.10.pem').Path
$env:CAT_FOCUS_TLS_KEY = (Resolve-Path '.\192.168.1.10-key.pem').Path
npm run build
npm run preview
```

将示例 IP 换成实际局域网 IP。根证书在签发机上由 `mkcert -CAROOT` 定位；把其中的 `rootCA.pem` 安装到两台手机并按系统提示启用信任。iPhone 还须在“设置 → 通用 → 关于本机 → 证书信任设置”启用完全信任。手机打开 `https://<局域网 IP>:4173/`，确认没有证书警告。Android Chrome 使用菜单“安装应用”；iPhone Safari 使用分享菜单“添加到主屏幕”。证书与私钥只用于本地测试，不要发布或提交。普通局域网 HTTP 不能用来验证安装、Service Worker 和通知等安全上下文能力。

首次联网打开后等待缓存完成，再断网重新打开测试。PWA 的系统通知仅在打开应用且用户主动允许后尝试；首版没有推送服务，因此关闭应用后的准时锁屏提醒不在保证范围内。返回应用时会按时间结算并显示页面内完成提示。

离线验证请使用 `npm run build` 后的预览或部署版本。开发服务使用网络加载文件，避免旧缓存遮住最新修改；更新后如暂未看到“管理”按钮，请刷新页面。

## M1 独立猫爪币钱包

每累计1分钟有效专注获得1 XP，等级门槛不变；每累计5分钟迁移后新增的有效专注获得1币。余额可消费，经验不会因花币减少。首次升级旧币清零，历史时长不补币；进行中会话以迁移瞬间的有效时长为界，暂停和迁移前时长不计入新币，未结算的已到点旧会话也不会补发。放弃不发币、不增加进度。

备份v5包含钱包余额、收入/支出流水、剩余进度与发币凭据。可恢复到未发生专注收入或消费的钱包；自动签到奖励按日期去重保留，避免首次打开获得5币后无法恢复备份。相同快照重复导入不发币，有新增专注收入、进度或消费的钱包冲突时仍整批拒绝。存在活动专注时，不恢复不同的钱包快照，请先结束会话。旧版备份可继续合并记录，但不会改余额、零头或发币；这些导入记录仍按原规则计入XP。详情见 [M1交付与验证](art/economy-m1/README.md)。

M3已提供猫咪商城；扣币、购买记录、所有权和入住状态在同一事务内提交。连续签到奖励尚未实现。

## M2 每日欢迎与自动签到

每天首次打开或回到前台时，按设备本地自然日自动领取5猫爪币，无需点击领取。成功提交后显示“今日签到成功！”；主按钮只关闭弹窗并转到专注页，不启动计时。关闭或刷新后当天不再弹出。已领养时可显示主陪伴猫idle装饰，未领养时显示猫爪图形。

有运行或暂停中的专注时，只显示不阻断的签到成功提示，不暂停、重置或结束计时。有其他弹窗时延后欢迎界面。前台跨日会自动检查；后台返回时重查日期。签到完全在本地完成，离线可用；失败不显示成功，会在返回应用或稍后重试。

历史记录包括本地日期、领取时间、5币奖励和交易ID，保存在现有settings的dailyCheckins中；与钱包及流水一起原子提交。数据库保持v5；当前备份v6显式保存签到历史，并与daily_checkin流水交叉校验。日期回拨到已签到日期也不会重复发币；本阶段不联网校时、不实现复杂防作弊。

验证与实际截图见 [M2交付记录](art/economy-m2/README.md)。没有连续天数、额外奖励、成就或补签。猫咪商城见下方M3/M4说明。

## M3 商城与 M4 兼容验收

从猫咪小屋进入商城，不增加底部导航。猫咪商品沿用真实资源配置，初始领养猫已拥有，其余每只80币；余额不足禁止购买，重复确认和多页面并发均不会重复扣币。购买后自动入住，最多三只；切换主陪伴猫同步专注、统计和小屋。家具仅展示四区基础物品的默认拥有、已装备状态，不收费，不提供替换操作。

数据库继续为v5，商城状态使用settings，购买与钱包流水跨存储事务提交。备份v6包含独立钱包、结算进度、签到、商城、猫咪状态及版本信息；XP和等级仍由有效专注记录计算。旧v1–4文件只合并历史，不将历史换新币；v5钱包继续受原有冲突保护。不能直接相加两个钱包；仅对无专注收入、无消费和无零头的本机钱包保留按日期去重的未消费签到奖励，再恢复备份。钱包、商城、猫咪或记录冲突会整批回滚，请勿把导入当作任意两台设备的同步功能。

自动化与实际浏览器验证、截图及手机未实测项目见 [V0.2最终开发报告](art/release-v0.2/README.md)。M1/M2旧报告中的版本号描述当时状态；最新数据库和备份版本以开头 Focus List 说明为准。

顶部通知提示显示4秒后自动消失，也可点叉关闭；新的提示重新计时。购买、结束专注等操作确认窗口仍需用户操作。

## V0.3 阶段1：小屋交互底座

在小屋点击猫咪可选中互动对象，独立于主陪伴猫；点击猫窝、食盆、水盆、地毯或猫抓板可选择家具目标。没有选猫时，面板会提供入住猫供选择。交互面板位于场景下方，五种行为暂时禁用并标明尚未开放，猫咪继续待机，不产生奖励或数据变更。离开小屋会清空临时选择，数据库/备份版本不变。

## V0.3 阶段2A：动画资源与通用播放器

最新交互V2取消进入/退出段，实际接入三猫12段、204帧：吃饭/喝水/抓挠循环及抚摸单次。通用播放器支持逐帧时长、单次完成、循环停止、取消和加载失败恢复，原idle/sleep继续沿用。行为按钮仍未开放，没有自主调度或功能区移动。

详见 [阶段2A资源核对和交付报告](art/interaction-v0.3/stage-2a/README.md)。预缓存只增加V2移动WebP和清单，排除旧V1及交互原始大PNG；原始文件保留维护。数据库与备份版本不变。

## V0.3 阶段2B：传送与手动行为

在小屋选猫后可以抚摸，或选择食盆、水盆、猫抓板、猫窝进行短时互动。传送淡出150ms、完全透明后换位、淡入180ms；动作结束或取消会返回原站位。食盆、水盆共享占用组，忙碌时提示稍后再试。同猫恢复完成前不能启动新行为，其他猫独立运行。

最新V2没有enter/exit，配置允许缺省阶段，不伪造素材。当前时长为吃饭4.8秒、喝水6秒、抓挠3.84秒、睡眠9.6秒，抚摸只播一次；时长和传送参数集中配置。没有自主调度或互动奖励，行为仅存在小屋内存，切页/刷新清理，数据库和备份版本不变。

详见 [阶段2B交付与验证](art/interaction-v0.3/stage-2b/README.md)。阶段1/2A文档中的禁用按钮描述为当时交付状态，当前行为以本节为准。

## 数据规则

- 活动会话只保留一份。计时使用时间戳重算，暂停时不累计；到点以计算出的到点时间归属日期。
- “提前结束并保存”会保存实际有效秒数，计入统计和奖励；“放弃且不保存”不计入统计或奖励。
- 已保存记录总秒数每满 60 秒获得 1 经验；新钱包只按迁移后新增且已保存的有效专注每满300秒获得1猫爪币，不足部分跨会话保留。等级 `n` 门槛为 `30 × n × (n − 1)` 分钟。
- 周一为一周起点；月份逐周统计的首尾周只包含所选月份内日期。
- JSON 备份格式版本为 8，包含专注清单与当前目标选择、记录目标快照、类别、记录、成长校验信息、独立钱包、流水/发币凭据、签到历史、购买/家具槽位及可选的 `catHouse`；继续兼容版本 1–7，版本 1、2 的记录按倒计时兼容。导入完整校验后按记录 ID 合并；同 ID 内容冲突则整批拒绝。同名类别合并关联，保留本机已有类别的停用状态和当前选择；新增类别按备份顺序追加。任务按 ID 合并，同 ID 内容冲突时整批拒绝；保留本机有效任务选择，本机未选择时恢复备份中的有效待办目标。旧备份不清空清单或选择，无效引用清除。活动会话、总结查看状态及其他本机设置不参与备份。浏览器数据可能被清除，请定期导出。
- 领养状态仍保存在settings存储中；M1另建钱包相关存储，不修改领养数据。导入时，本机未领养可恢复备份中的领养；双方领养状态冲突时整批拒绝，记录和类别也不写入。旧备份或没有 `catHouse` 的备份不会清除本机领养。相同备份可重复导入。状态校验包括有效 ID、无重复、入住猫已拥有、最多三只入住及有效主陪伴猫；首次免费领养一只，其余通过商城购买。

## V0.3 阶段 3：自主行为

小屋进入前台后约 8–10 秒开始自主吃饭、喝水、抓挠或睡觉；最多两只猫同时活动，手动互动优先。离开小屋或进入后台会停止调度，回来后重新安排。动作完成后留在家具区；必要时回原站位腾出空间。

稳定家具位置保存在本机设置，刷新恢复；不保存正在传送/播放的临时状态，不改变数据库 v5 和备份 v6。位置不随 JSON 备份跨设备恢复。

本阶段测试：34 文件、183 项通过；类型检查与生产构建通过。具体实现、浏览器实测与手机未验证项目见 [阶段 3 验收报告](art/interaction-v0.3/stage-3/README.md)。
